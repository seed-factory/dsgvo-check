Файл `docs/04-quality-and-delivery.md` — качество, CI и поставка. Аудитория: разработчики и тот, кто будет встраивать сканер в CI.

Разделы:
1. Пирамида тестов L0–L4 — что на каждом уровне, где запускается, сколько длится.
2. Правило пар фикстур (нарушение / чистая / inconclusive) и автоматический тест полноты.
3. Офлайн-инфраструктура тестов — fixture-server, egress-прокси с картой хостов, тестовый CA и сертификаты (просроченный, чужое имя, неполная цепочка, TLS 1.0), фейковый DNS, `--network none`.
4. Имитация CMP — собственные симуляторы и CMP-лаборатория, с учётом лицензий.
5. Запись артефактов из L2 для L1, golden-тесты JSON, контрактные тесты схемы.
6. Канареечный прогон по 10 сайтам заказчика — условия и согласие, частота, что считается регрессией, хранение результатов.
7. Борьба с флейками.
8. CI самого проекта — матрица GitHub Actions, обязательные проверки, лицензионный allowlist зависимостей, бюджет времени.
9. GitHub Action — тип, входы и выходы, пример workflow, пример репозитория, где сборка падает (этап 2 ТЗ).
10. GitLab — шаблон и CI/CD component, пример.
11. Docker-образ — база, браузер, non-root, sandbox, seccomp, размер, multi-arch, теги и digest.
12. npm-пакет и установка браузера.
13. Релизы — версии тула и схемы, инструменты релиза, provenance, подписи, SBOM, обновление баз (VULN, каталоги) и браузера.
14. Безопасность сканера — модель угроз, изоляция в CI, SSRF, секреты, лимиты ресурсов.
15. Безопасность HTML-отчёта — экранирование, CSP, без внешних ресурсов, без JS.
16. Данные в CI-артефактах — минимизация, срок хранения.
