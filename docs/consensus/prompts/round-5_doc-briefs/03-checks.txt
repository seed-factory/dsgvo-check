Файл `docs/03-checks.md` — спецификация проверок. Аудитория: разработчик проверки и DSGVO-эксперт заказчика, который вычитывает правовую часть.

1. Сводная таблица всех ID каталога (P0, P1, P2) и служебных диагностик `SCAN-*`: ID → приоритет → модуль и фаза → уровень по умолчанию → crmCode → этап плана.
2. По каждому ID — раздел с одинаковой структурой:
   - **Что ловим**
   - **Данные и фаза**
   - **Алгоритм детекта** — по шагам
   - **Evidence** — поля и что редактируется
   - **Уровень** — по умолчанию; правила понижения и `inconclusive`
   - **Ложные срабатывания и пропуски** → защита
   - **Фикстуры** — нарушение / чистая / inconclusive, конкретно что в каждой
   - **Правовой якорь** — нормы и статус позиции, кратко, без выводов
   - **Текст находки** — ключ сообщения и черновик немецкой формулировки в нейтральном стиле («… nicht gefunden …»), с пометкой «Entwurf — Prüfung durch Auftraggeber»
   - **Открытые вопросы**
   P0 и CONSENT-05 — подробно, P1 — средне, P2 — кратко.
3. В конце — ошибки и неясности каталога (crmCode, примеры, приоритеты), которые нужно подтвердить у заказчика.
