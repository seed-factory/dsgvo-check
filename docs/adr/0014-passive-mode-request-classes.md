# ADR-0014 — Пассивный режим: классы запросов O, T, E

Этот документ фиксирует, какие запросы к сайту сканер вправе делать по умолчанию, какие — только по явному флагу, и чего не делает никогда. Нужен разработке (валидатор `ProbeSpec`), авторам README и юристу заказчика.

## Статус

`Accepted` — D18: E — единогласно; TLS-04 — T при включённой проверке; DKIM — 3:1 (против Sol-К) и вопрос 16 (generic-селекторы и запрет «перебора» в ТЗ; до ответа действует порядок ниже). Список путей FILE-01 и ADMIN-01 ждёт правовой оценки заказчика (вопрос 15), но вне релиза и на решение о классах не влияет. Дата: 2026-10-30.

## Контекст

- ТЗ: «только пассивные проверки», «не долбить сайт», запрет перебора, инъекций и обхода авторизации — сканер запускают по чужим сайтам.
- § 202a StGB требует «besonders gesichert» и преодоления защиты — при открытой отдаче его нет, но дело Modern Solution (AG Jülich 17.01.2024, BVerfG Nichtannahme 15.09.2025, ⚠ проверить Az., факт 27) показывает серую зону при чтении содержимого. § 303b StGB как основание rate limit отклонён (требует Nachteilszufügungsabsicht); основание — § 823 BGB и BGH I ZR 224/12 (Screen Scraping).
- Ресёрч R1 предлагал FILE-01 по умолчанию с ~30 путями; Fable-П — ADMIN-01 «базовый профиль» и одновременно opt-in.

## Решение

Каждая проверка описывает дополнительные запросы декларативным `ProbeSpec`; валидатор относит их к одному из трёх классов и отклоняет всё вне таблицы.

| Класс | Что входит | Режим |
|---|---|---|
| **O** — наблюдение | Браузерные навигации по 6 страницам и подзагрузки сайта; фазы A, A′, B, C, M ([ADR-0009](0009-consent-phases.md)) | всегда |
| **T** — технические пробы, только для включённых проверок | DNS ≤ 60 запросов (DMARC Tree Walk ≤ 8, SPF ≤ 10 lookups, DKIM ≤ 25 TXT, CAA, MX); 2 TLS-handshake (TLS 1.0 и 1.1) для TLS-04 без завершения и без перебора шифров; `http://`-цепочки host/www/apex с ручными редиректами ≤ 5; `/.well-known/security.txt` и `/security.txt`; Stage-2 `readme.txt`/`style.css` ≤ 20 только для уже обнаруженных плагинов | по умолчанию при включённой проверке |
| **E** — exposure | `--exposure-probes`: FILE-01 ≤ 15 фиксированных путей из списка заказчика, один GET, `Range: bytes=0-4095`, 4 KiB неотключаемо, тело не хранится, секреты не используются, без рекурсии; ADMIN-01 — 3 GET (`/wp-json/wp/v2/users` только число, `/?author=1` только факт, `/xmlrpc.php` код 405), без попыток входа | opt-in, вне релиза, после правовой оценки |

- **DKIM:** сначала `--dkim-selector`, затем документированные селекторы провайдера по MX, затем короткий generic-список, всего ≤ 25 TXT к авторитетному DNS. Результат «unter N geprüften Selektoren nicht gefunden» — только `info`; «DKIM fehlt» не пишется. `warning` — ключ < 1024 бит или заданный пользователем селектор отсутствует или отозван. Совместим ли generic-список с запретом «перебора» в ТЗ, решает заказчик (вопрос 16); каталог сам описывает MAIL-03 как поиск «на распространённых селекторах».
- **Вежливость:** навигации по одной с паузой ≥ 1,5 с; HTTP-пробы ≤ 2 запр./с на хост; потолок 2 000 браузерных запросов. Перегрузка — общая политика для браузера и проб ([ADR-0009](0009-consent-phases.md)): 429/503 трижды подряд на пробах, на навигации или ≥ 3 за фазу в браузере → пауза по `Retry-After` ≤ 30 с, один повтор, затем новых запросов к хосту нет, `SCAN-THROTTLED`; никаких retry-штормов.
- **Никогда:** перебор путей и параметров, инъекции, попытки входа, отправка форм, вызовы XML-RPC, обход CAPTCHA, WAF и бот-блоков, stealth-маскировка, использование найденных ключей.
- README: флаг пользователя не создаёт разрешения владельца сайта; инструмент предназначен для собственных и мандатных сайтов.

## Рассмотренные варианты

| Вариант | Плюс | Минус |
|---|---|---|
| Три класса с валидатором, E opt-in вне релиза (выбран) | Граница пассивности проверяема в L0; релиз без серой зоны StGB | FILE-01 и ADMIN-01 ждут правовой оценки |
| FILE-01 по умолчанию, ~30 путей (ресёрч R1) | Частые находки `.git`, `.env` | Серая зона § 202a при чтении содержимого; «не долбить» |
| DKIM только по заданным или документированным селекторам (Sol-К; вариант (б) вопроса 16) | Нет «перебора» | Больше ложных «nicht gefunden»; запросы и так идут к DNS, а не к сайту |
| `warning` для провайдеров с фиксированными селекторами (Fable-К, Opus-П) | Точнее для IONOS/Strato | Google допускает свой префикс; MX не определяет домен подписи — отменено |
| Token-bucket 2 запр./с на браузерный трафик через CONNECT (Fable-П) | Единый лимит | Без MITM туннель не раскрывает HTTP/2-запросы; лимит искажает измеряемое |

## Последствия

- Класс запроса — часть `ProbeSpec`, проверяется тестом L0; новая проба вне таблицы не проходит сборку.
- `scan.environment.requestsIssued {navigations, probes, dns, tls}` показывает фактическую нагрузку.
- TLS-04: план А — сырой ClientHello через `net.Socket`, план Б — `DEFAULT@SECLEVEL=0`; неспособность клиента (self-test) — `error` сканера, не находка (спайк С4).
- FILE-01 с кодом «T0» и ADMIN-01 остаются `crmCode: null` до справочника.
